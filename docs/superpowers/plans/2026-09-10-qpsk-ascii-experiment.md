# QPSK ASCII Communication Experiment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify a reproducible MATLAB/Simulink R2022b experiment that sends ASCII through a Gray-coded, RRC-filtered QPSK AWGN link and produces report-ready functional and BER results.

**Architecture:** Focused MATLAB functions form the testable reference implementation, while a programmatically produced and checked-in Simulink model mirrors the physical chain and logs its important nodes. One configuration structure drives the reference path, model, tests, and reporting scripts; `run_all.m` is the clean regeneration entry point.

**Tech Stack:** MATLAB R2022b, Simulink 10.6, Communications Toolbox 7.8, DSP System Toolbox 9.15, Signal Processing Toolbox 9.1, `matlab.unittest`

**Spec:** `docs/superpowers/specs/2026-09-10-qpsk-ascii-experiment-design.md`

## Global Constraints

- Default message: `HELLO HEU`.
- ASCII is unsigned 8-bit, most-significant bit first, and input text is limited to 7-bit ASCII.
- Modulation is unit-average-power Gray QPSK with two bits per symbol.
- RRC rolloff is 0.35, samples per symbol is 8, and filter span is 10 symbols.
- Eb/N0 sweep is `0:2:12` dB.
- MATLAB randomness uses separate fixed functional and BER seeds.
- Figure titles are Chinese; variables and filenames remain English; technical axis labels may remain English.
- The checked-in `.slx` must run on R2022b. Prefer stable, simple model construction over perfect automation.
- Do not add GUI, synchronization, coding, frequency-offset compensation, hardware deployment, or complex framing.

## File Map

- `src/qpsk_config.m`: sole source of shared parameters and repository paths.
- `src/ascii_to_bits.m`, `src/bits_to_ascii.m`: strict ASCII conversion.
- `src/qpsk_modulate.m`, `src/qpsk_demodulate.m`: documented Gray mapping.
- `src/simulate_qpsk_link.m`: RRC/AWGN/matched-filter reference chain.
- `src/save_figure.m`: consistent PNG/FIG export.
- `run_functional_demo.m`: message verification and node artifacts.
- `run_ber_experiment.m`: deterministic Monte Carlo BER experiment.
- `build_qpsk_model.m`, `run_simulink_demo.m`: model construction and execution.
- `src/run_experiment.m`, `run_all.m`: testable orchestration and clean entry point.
- `tests/TestCodingAndModulation.m`, `tests/TestQpskLink.m`, `tests/TestReports.m`, `tests/TestSimulinkModel.m`: automated verification.
- `README.md`: exact execution and artifact instructions.
- `model/qpsk_ascii_system.slx`: runnable submission model generated during implementation.
- `results/`: reproducible report artifacts generated by `run_all.m`.

- [ ] **Step 3: Implement the offline RRC chain with explicit noise scaling**

Use `h = rcosdesign(cfg.rolloff,cfg.filterSpanSymbols,cfg.sps,'sqrt').';`,
explicit zero insertion, and full convolution. With unit-energy `h` and unit
symbol energy, add complex noise with `E[abs(n)^2] = 1/(2*EbNoLinear)`:

```matlab
txSymbols = qpsk_modulate(bits);
upsampled = zeros(numel(txSymbols)*cfg.sps,1);
upsampled(1:cfg.sps:end) = txSymbols;
txWaveform = conv(upsampled,h,'full');
if isinf(ebnoDb)
    noise = zeros(size(txWaveform));
else
    n0 = 1/(cfg.bitsPerSymbol*10^(ebnoDb/10));
    noise = sqrt(n0/2)*(randn(size(txWaveform))+1i*randn(size(txWaveform)));
end
rxWaveform = txWaveform + noise;
matchedWaveform = conv(rxWaveform,h,'full');
totalDelay = numel(h)-1;
indices = totalDelay+1:cfg.sps:totalDelay+1+(numel(txSymbols)-1)*cfg.sps;
rxSymbols = matchedWaveform(indices);
```

Populate every output field and calculate errors with `nnz(rxBits ~= bits)`.

tempResults = tempname; mkdir(tempResults);
cleanup = onCleanup(@() rmdir(tempResults,'s')); %#ok<NASGU>

b = run_ber_experiment(c);
verifyEqual(t,b.theoretical,qfunc(sqrt(2*10.^(c.ebnoDb/10))), ...
    'AbsTol',1e-14);
verifyEqual(t,size(b.simulated),size(c.ebnoDb));
verifyGreaterThan(t,b.bitsTested,zeros(size(c.ebnoDb)));
sigma = sqrt(b.theoretical.*(1-b.theoretical)./b.bitsTested);
verifyLessThanOrEqual(t,abs(b.simulated-b.theoretical), ...
    max(5*sigma,0.4*b.theoretical));
verifyTrue(t,isfile(fullfile(tempResults,'ber_results.csv')));
verifyTrue(t,isfile(fullfile(tempResults,'ber_curve.png')));
end
